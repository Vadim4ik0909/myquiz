# Project Context (Project.md)

Цей документ визначає архітектуру, мету та правила розробки **ADHD Квіз-Платформи 120%**.

---

## 🎯 Мета проєкту
**ADHD Квіз-Платформа 120%** — це високопродуктивний, гейміфікований веб-додаток для інтерактивного вивчення англійської лексики та підготовки до іспитів, оптимізований для фокусування (ADHD-friendly), швидких сесій тренувань та детальної аналітики.

---

## 🛠️ Технологічний стек
- **Frontend Core:** HTML5, Vanilla CSS3 (Custom CSS variables), Vanilla JavaScript (ES6+).
- **Збереження даних (Persistence):** LocalStorage (`my_quiz_modules`, `my_quiz_mem_stats`, `my_quiz_streak`, `my_quiz_settings`).
- **Словникова база за замовчуванням:** [`database.js`](file:///Users/user/Desktop/my-quiz-local/database.js) (об'єкт `DEFAULT_MODULES` із 15 юнітами та 3100+ лексичними парами).
- **Синтез мовлення:** Web Speech API (`speechSynthesis`) для автоматичної вимови англійських слів.

---

## 📁 Структура проєкту
- `index.html` — основний односторінковий додаток (Single Page Application).
- `database.js` — глобальна база даних модулів за замовчуванням (`DEFAULT_MODULES`).
- `modules/` — каталог із вихідними Quizlet `.txt` файлами для імпорту.
- `Design.md` — інструкції та візуальні стандарти дизайну.
- `Project.md` — цей документ архітектури та контексту.

---

## 🛑 Суворі правила та обмеження (Constraints)
1. **Збереження сумісності:** Не ламати логіку алгоритму інтервального повторення (`updateMemoryAlgorithm`) та відстеження стріку (`STREAK_DATA`).
2. **Мульти-варіантний нечіткий пошук (`isFuzzyMatch`):** Завжди зберігати розділення відповідей за роздільниками `/`, `;`, `,`, `:`, `()` для точного розпізнавання синонімів.
3. **Офлайн-першочерговість:** Додаток повинен працювати в браузері автономно без обов'язкових зовнішніх серверних залежностей.
4. **Контекст дизайну:** Будь-які зміни інтерфейсу повинні суворо дотримуватися палітри та правил із [`Design.md`](file:///Users/user/Desktop/my-quiz-local/Design.md).
