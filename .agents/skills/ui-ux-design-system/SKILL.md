# UI/UX Design System Standard

Цей скіл закріплює дизайн-стандарти та правила естетики інтерфейсу проєкту `my-quiz-local`.

## 1. Колірна палітра (Catppuccin Mocha Dark Theme)
Усі нові компоненти, панелі, кнопки та картки повинні суворо використовувати визначені CSS-змінні проєкту:
- **Фон сторінки:** `var(--bg)` (`#1e1e2e` / `base`)
- **Поверхні карток:** `var(--surface)` (`#181825` / `mantle`) та плашки `#252538`
- **Межі та рамки:** `var(--border)` (`#313244` / `surface0`) та `#45475a`
- **Основний текст:** `var(--text)` (`#cdd6f4`)
- **Вторинний текст/підказки:** `var(--subtext)` (`#a6adc8`)
- **Акцентні кольори:**
  - `var(--accent)` (`#89b4fa` — Blue / Лавандово-блакитний)
  - `var(--green)` (`#a6e3a1` — Green / Успіх, правильна відповідь)
  - `var(--red)` (`#f38ba8` — Red / Помилка)
  - `var(--orange)` (`#fab387` — Peach / Контекст, стрік)

## 2. Радіуси заокруглень та відступи (Geometry & Spacing)
- **Картки та панелі:** `border-radius: 14px` або `16px`.
- **Внутрішні плашки та селектори:** `border-radius: 10px` або `12px`.
- **Кнопки та бейджі:** `border-radius: 8px` або `10px`.
- **Сітка відступів:** кратна 4px (4px, 8px, 12px, 16px, 20px, 24px).
- Суворе збереження візуальної ієрархії без перевантаження інформацією.

## 3. Тіні, оверлеї та анімації (Lighting & Motion)
- **Заборона важких тіней:** Заборонено використовувати неприродні глибокі чорні тіні (`box-shadow: 0 20px 50px #000`). Використовувати делікатні напівпрозорі акценти:
  ```css
  box-shadow: 0 4px 16px rgba(0, 0, 0, 0.25);
  border: 1px solid var(--border);
  ```
- **Відсутність різких оверлеїв:** Замість непрозорих або блокуючих екранів застосовувати висувні бічні панелі (Split View / Side Drawer) або вбудовані картки.
- **М'які переходи:** `transition: all 0.2s cubic-bezier(0.16, 1, 0.3, 1)` або `cubic-bezier(0.4, 0, 0.2, 1)`.
