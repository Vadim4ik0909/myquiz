# Frontend Clean Architect (UI Architecture & Performance Standard)

Цей скіл визначає обов'язкові правила для створення легкого, швидкого та естетичного інтерфейсу в проєкті `my-quiz-local`.

## 1. Захист від роздування коду (Anti-Bloat & DOM Optimization)
- **Точкові зміни:** Заборонено безконтрольне нарощування розмітки. Будь-який новий блок має гармонійно вбудовуватися в існуючу ієрархію екранів.
- **Мінімум важких DOM-елементів:** Категорично заборонено генерувати надлишкові глибоко вкладені обгортки (`div > div > div`), важкі оверлеї чи непрозорі затемнення, якщо задачу можна вирішити чистим CSS або вбудованою панеллю.
- **Чистка DOM:** Динамічні елементи (підказки, сповіщення) повинні своєчасно очищатися або перевикористовуватися.

## 2. Скролбари та плавність (No Scrollbars & Fluid GPU Transitions)
- **Повна відсутність паразитарних скролбарів:**
  - Усі модальні вікна, висувні панелі (Side Drawers), картки квізу та списки повинні мати:
    ```css
    scrollbar-width: none !important;
    -ms-overflow-style: none !important;
    ```
    та для WebKit:
    ```css
    &::-webkit-scrollbar {
        display: none !important;
        width: 0 !important;
        height: 0 !important;
    }
    ```
  - Горизонтальний скрол (`overflow-x`) на рівні сторінки та карток суворо заборонений (`overflow-x: hidden`).
- **Апаратне прискорення (GPU Acceleration):**
  - Анімації появи та зсуву виконувати тільки через властивості `transform` (`translate3d`, `translateY`, `scale`) та `opacity`.
  - Заборонено анімувати `width`, `height`, `left`, `right`, `margin` під час активних переходів.
  - Використовувати плавні криві швидкості: `cubic-bezier(0.16, 1, 0.3, 1)`.
  - Уникати масивних розмитих тіней (`box-shadow`), що створюють падіння FPS.

## 3. Економія ресурсів та менеджмент подій (Event Management)
- **Заборона дублювання Event Listeners:**
  - Глобальні слухачі (`keydown`, `click`, `resize`) мають бути єдиними (делегованими або централізованими).
  - Перед додаванням слухача перевіряти, чи подія вже не обробляється у `main.js`.
- **Енергоефективність:** Зупиняти таймери (`stopLiveTimer`, `clearInterval`, `clearTimeout`) при переході між екранами або закритті сесій.
