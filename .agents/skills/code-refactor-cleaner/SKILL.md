# Code Refactor Cleaner (Code Hygiene & Anti-Dead-Code Standard)

Цей скіл регламентує правила аудиту та оптимізації кодової бази проєкту `my-quiz-local` для уникнення накопичення технічного боргу.

## 1. Контроль «мертвого» коду (Dead Code Detection)
- **Функції та змінні:** При зміні логіки або рефакторингу обов'язково перевіряти, чи не залишилися невикористовувані глобальні змінні або застарілі функції-хелпери.
- **CSS-класи:** При видаленні або переробці UI-елементів своєчасно видаляти відповідні селектори з `style.css`.
- **Заборона "зомбі-коду":** Не залишати закоментовані великі блоки невикористовуваного коду в релізних версіях.

## 2. Запобігання витокам пам'яті (Memory Leak Prevention)
- **Слухачі подій (`addEventListener`):**
  - Не створювати анонімні слухачі подій всередині функцій, що викликаються циклічно або при кожному запитанні (`showQuestion`, `render...`).
  - Використовувати делегування подій на постійні контейнери або централізовані глобальні слухачі (`document.addEventListener`).
- **Таймери та анімації:**
  - Будь-який запущений таймер (`setTimeout`, `setInterval`, `requestAnimationFrame`) повинен мати точку обов'язкового клінапу при скиданні стану або переході на інший екран (`stopQuizSession`, `handleBackNavigation`).

## 3. Регулярний аудит кодової бази (Sanity Checks)
- **Перевірка синтаксису:** Після будь-якої модифікації обов'язково запускати:
  ```bash
  node -c scripts/main.js
  ```
- **Мінімалізм:** Усі виправлення повинні бути хірургічно точними (diff-based), без роздування кількості рядків.
